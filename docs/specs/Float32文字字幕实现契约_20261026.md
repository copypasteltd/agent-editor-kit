# Float32文字字幕实现契约（2026-10-26）

目标是把现有可编辑文字接入明确选择的线性 Float32 时间线，保留原媒体精度、作者时钟及可恢复交付。此批不改变 G01–G38 的关闭条件，也不把原生字形覆盖率宣称为浮点覆盖率或 GPU 排版。

1. **图像边界**：`FloatTextHost` 返回自有、连续 H×W×4 Float32 straight RGBA。零alpha的RGB清零。文字原生进程只接收透明画布，不接收原媒体。宿主媒体效果、字层绘制、裁切、蒙版、仿射与混合的顺序必须在结果中声明。
2. **颜色边界**：作者填充、描边、阴影、底框颜色按既有原生解析器取得确定RGBA，再从sRGB解释到显式线性工作域。每个组件使用独立覆盖率，顺序为底框、阴影、描边、填充；straight source-over 由独立 Float64 参考核验。动画alpha在完整字层只乘一次。
3. **原生覆盖率**：drawtext覆盖率为8bit，当前转换器的Float32白值不假定为1。对三RGB通道、两行、全部256输入码校验重建整数码；任何非零重建误差都拒绝。校准绑定FFmpeg SHA，仅对覆盖率使用，不修改原媒体颜色。
4. **作者时间**：生成字层的时间来自完整作者起点加原展示tick，窗口使用原偏移。父级倒放传递左极限，文字自身媒体定格仍使用展示时钟。表达式使用明确时间常量；打字机在该时间取完整字素前缀，不使用CFR文字影片缓存。
5. **排版与高亮**：明确本地字体和真实度量；整段锚点、基线、塑形流程复用现有原生布局。高亮二值选择完整正常/活动段落，避免重复描画。复杂Bidi/内部塑形簇按现有限制拒绝。
6. **SRT**：纯文本、全部非空块必须成功解析；正半开时窗、整数tick偏移、明确sequence/clip时钟。错误块、富样式标签及未经移植的文件动画不得忽略或回落8位libass。
7. **依赖与资源**：字体/SRT/原生工具/文字实现/Pillow布局依赖绑定SHA并进入标准命令读锁。默认64MiB LRU、20个完整Float32栅格的准入估算、最大768MiB单次工作区；不把这些声明为进程RSS硬限制。4K文字在默认上限前置拒绝。取消时回收自有进程及读取线程，不影响外部任务。
8. **交付核验**：同一冻结源码构建到独立目录并比对213文件；安装版专项、浮点、标准渲染、默认文字及CLI回归分别留证。真实统一Skill执行预览、成片、取消恢复、队列、质量检查及可编辑包往返；核对原媒体/音频、字体许可与历史记录。

使用逻辑、字段与边界见[功能手册](../product/FLOAT_TEXT.md)，实际结果见[当轮报告](../validation/Float32文字字幕实测_2026-10-26.md)。4K/GPU文字、富ASS、复杂排版、HDR、自然视听与完整剪映等价继续实现或验收。
