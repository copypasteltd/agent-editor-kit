## 安装后验收命令

在仓库根目录原生 PowerShell 中，以下路径均位于 E 盘。需要本机已有 Windows CPython3.13 x64 与 FFmpeg，不使用 Docker、WSL、虚拟环境或全局安装。

```powershell
$aekInstalled = 'E:/dev/sandbox/AI广告剪辑/local/agent-ffmpeg/v0.1.0-alpha.4-local.51/final-r1/installed'
C:/Python313/python.exe -I -S -B -u -X utf8 docs/validation/probe_aces_installed.py --installed $aekInstalled --run installed-native-r1
C:/Python313/python.exe -I -S -B -u -X utf8 docs/validation/test_aces_delivery.py --installed $aekInstalled --group special --run installed-special-r1
C:/Python313/python.exe -I -S -B -u -X utf8 docs/validation/test_aces_delivery.py --installed $aekInstalled --group meter --run installed-meter-r1
C:/Python313/python.exe -I -S -B -u -X utf8 docs/validation/test_aces_delivery.py --installed $aekInstalled --group compat --run installed-compat-r1
```

上述运行名称保护已有证据；重试需使用新名称，不能覆盖先前失败或通过记录。安装构建候选、测试完成和本地入口切换是三个不同状态。仅运行配置枚举或验证文件存在，不能替代实际视频、音频或原生库执行验收。
