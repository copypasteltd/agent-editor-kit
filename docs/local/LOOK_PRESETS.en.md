## Naming and measurement

`sp-` = Striped Purple (49); `t3-` = t3mujinpack (51); `nt-` = Natron (267); `fl-` = FreshLUTs (133). Numbering 001–500 is for reading; commands always use the ID. Natron `curve-plus-N` / `curve-minus-N` preserves the original +/- curve suffix; it does not specify EV or a runtime intensity setting. Film/product names identify community approximations, without manufacturer endorsement.

Measurements use full strength, tetrahedral interpolation and encoded SDR RGB, with output clipped to 0..1. Y′ = 0.2126 R′ + 0.7152 G′ + 0.0722 B′, expressed in 0–255 code values; it is not linear luminance or exposure. Span = (Y′75% − Y′25%) / 127.5. Swatches do not establish skin protection. Suggested scenes/intensity are selection starting points, with no natural-footage acceptance. LUTs do not generate grain, glow, vignettes, haze or beauty effects.
