# Public resource example

12 s, 360 × 640, 30 fps, 360 fully decoded frames. The GIF is a silent 8 fps preview. MP4 audio contains music and a short interface SFX; no generated speech.

- Original FIELD art: Agent Video Kit contributors, CC0; original input remains in `docs/assets/release-v0.1.0-alpha.3-r1/input/card-1.png`.
- GT RPG Frozen music: Juhani Junkala, CC-BY-4.0; https://opengameart.org/content/gt-rpg-soundtrack . Trim/gain/fades are applied, original is retained.
- Confirmation SFX: Kenney, CC0-1.0; https://kenney.nl/assets/interface-sounds .
- Noto Sans SC/TC: original font copyright holders, OFL-1.1; full notices in licenses/.
- Kodak Gold 200 creative LUT: João Almeida, MIT; strength 0.5, full original MIT/provenance retained. Trademark names do not imply endorsement.

Native installed CLI render, publish rights gate and full decode pass; human listening and continuous playback remain unreviewed. Reproduce with scripts/build_community_public_demo.py using the current installed CLI.
