# 仿射扫描行参数复用契约（2026-10-25）

目标：降低已交付六套运镜中旋转合成的重复计算，同时保持作者时钟、半像素采样、透明边缘和普通可编辑关键帧。完整 G32/其他 G01–G38 门槛不变。

实现前约束：只优化固定画布 `_affine_video_filters` 的纯数值变换表达式。每个颜色平面的每条扫描行在 `X=0` 更新自己的 AVExpr 寄存器，后续像素复用旋转/位置/缩放/锚点；不跨行、线程、平面或帧共享缓存，也不假设时间戳严格递增。保留浮点预乘→双线性一次采样→反预乘→RGBA 的顺序，不能用低分辨率或低质量代替性能改进。包含像素坐标或有状态函数的内部表达式继续走原逐像素路径。

依据：[FFmpeg n8.0 geq 源码](https://github.com/FFmpeg/FFmpeg/blob/n8.0/libavfilter/vf_geq.c) 的每平面/线程表达式和从 X=0 开始的行循环；[表达式实现](https://github.com/FFmpeg/FFmpeg/blob/n8.0/libavutil/eval.c) 的独立寄存器及惰性 if。源码阅读只是设计依据，需在本机实际 FFmpeg 上验证，未改动/分发 FFmpeg 源码。

验收：独立解析几何与冻结旧实现逐像素对照；多帧/非零时间戳/hold/Bezier/嵌套时钟/半透明隐藏 RGB；单线程和多切片输出一致。原生运镜/透明几何及 CLI 回归分别执行。旧版与新版用同一项目、图像、线程和编码参数做交错计时，至少三次，完整解码120帧并校验摘要；报告每次墙钟和中位数，不把历史并发负载下的65秒直接当作加速比基线。

交付：固定离线包、实际安装和统一 Skill、本机调用、原图/MP4/GIF、三语 README 和原始失败/成功记录。GPU仍只承担原来明确选择的编码；本优化是 CPU 仿射表达式复用，不声明 GPU 合成或全部长片/4K性能通过。
