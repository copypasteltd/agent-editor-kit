[使用流程](../product/SUBTITLE_DUBBING.md) · [事先建立的契约](../specs/字幕翻译配音联合流程契约_20261025.md) ·

本批实现普通 SRT → OPUS 中英翻译 → Kokoro 批内复用 → 完整声音时窗检查 →
可编辑音轨/双语字幕 → 原子工程提交。通过的是明确的工程行为；自然发音、语义接受、
多语种、说话人分离、字词精标、口型与完整 G19 均未关闭。

## 代码与实际安装

新增 `dubbing.py` / `dubbing_cli.py`，扩展既有 community worker 和受管任务恢复。
SRT 保留原编号/顺序/毫秒；控制器独立读取 WAV 的格式、实际样本、RMS、哈希和重试语速。
`reject` 超窗不提交；显式 `speed` 最多三次完整重生成，不截台词、不改译文、不放宽窗口，
原始及重试声音均保留。手动逐 cue 选角与重叠混音需要明确参数。

发布声音、字幕、模型来源/许可证和报告后，一次外层事务保存资产、权利、时间线、快照和操作。
超窗保留未提交任务供试听；取消/超时和其他失败回滚。恢复同时保护工程资产及 active Rights
Ledger 的本地 evidence/license_url 引用，避免已提交模型许可证据被清理。

### 输入、声音和适配边界

| cue | 实际英文源文 | 原窗口 | GPU 完整 WAV |
|---|---|---|---|
| 1 | Keep every original clip. | 0–6 秒 | zf_001，54,406 samples / 2.2669167 秒 |
| 2 | Choose a clear product story. | 6.5–12.5 秒 | zf_002，66,911 samples / 2.7879583 秒 |
| 3 | Create another version in seconds. | 13–19 秒 | zf_003，64,401 samples / 2.683375 秒 |

实际 `speed` 案例将 cue 1 的窗口设为 1.813 秒：原始 54,406 samples 放不下，
第二次整句生成语速 1.2878787460930319，42,690 samples / 1.77875 秒，完整文本不变，
两次 WAV 都作为资产保留。1ms/reject 保留一次原声音；1ms/max-speed=1.1 保留两次声音后拒绝，
二者项目与权利元数据不变、没有半批发布。

每个正常 voice batch 报告一次 Kokoro 初始化。GPU 基本批初始化 9.395 秒、三段生成合计
6.643 秒，翻译 worker 0.824 秒；CPU 使用不同输入、不同量化包，分别 3.602/7.989/4.630 秒。
包含哈希、进程、加载和项目操作的实际基本调用 GPU 29.654 秒、CPU 22.488 秒，
相应 dry-run 82.173/56.615 秒。本次并行执行其他检查，不能据此算 GPU 加速比或独占性能。
跨命令常驻复用、冷/热 P50/P95、4K/长片/并发和全面 GPU 滤镜仍是 G32 开放项。

### 保留的翻译质量问题

cue 3 实际被 OPUS 译成 **“以秒数创建另一个版本 。”**，不适合作为已接受的广告译文。
CPU “创建另一个版本。”被译为 “Creates another version.”，也需语境校对。
本次保留原始译文、实际配音和编码字幕，未为展示改写后伪称模型原输出。
时窗和工程往返通过不解决这个语义问题；G19/G36 继续开放。

## 真实取消、超时与强制中断

[运行中控制](evidence/subtitle-dubbing-20261025-r1/control-r1/verification.json)：
两个 owner 真实运行本地模型，在观察到实际子 worker 后创建取消文件或等待总预算用尽。
Windows 进程句柄证明已观察到的子 worker 退出；分别返回 CANCELLED / PROCESS_TIMEOUT，
项目和权利元数据不变，任务目录清理。另有 3 次普通 CLI（两个 init、一次预检）；
不能只数普通调用而漏掉这两个被测 owner。

[三个真实强制结束边界](evidence/subtitle-dubbing-20261025-r1/crashes-r1/verification.json)：
首个真实文件发布后、元数据保存待提交、提交后但清理前。仅在目标边界注入观察暂停，
模型推理和恢复实现未替换；核对握手 PID 后只终止本次 owner。
前两者恢复原元数据并回收未提交输出；第三者保留已提交声音/字幕/报告和两份 MODEL-SOURCE.txt。
10 次普通 init/preview/recover/validate CLI 与三个被测 owner 分开计数。

范围仅受管四轨/配音任务及共享 helper 原生子进程树；旧缓存、其他 worker、断电、磁盘不足、
设备丢失、长并发/公平性及模型断点续算均未据此关闭。
