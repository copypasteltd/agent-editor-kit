# 可复用运镜包契约（实施前固定）

范围：G04 的版本化参数运镜和现有关键帧跨工程复用。保留 12 项旧目录及其参数；本次不改变来源时钟、跟踪算法、3D 摄像机求解或宣称完整剪映等价。

1. `motion pack list/inspect/create/capture/apply` 使用本地 JSON。包具有固定格式/版本、稳定 ID、作者/许可、有限数字参数及范围、规范 transform 属性和归一化有理时间。禁止表达式执行、远程资源、未知字段、重复键和过大输入。
2. 六个自制路径为轨道绕行、弧形推进、S 曲线、快速甩入停稳、呼吸漂浮和细节扫视。曲线路径是显式 65 个线性采样点；采样误差必须报告，不称解析 3D 摄像机。参数仅以仿射数值绑定，不能运行代码。
3. 应用生成普通可编辑关键帧。位置/旋转可相对静态基值相加、缩放可相乘、透明度/锚点有范围检查；不改变资产、源入出点、变速、倒放、冻结或未涉及属性。现存相同属性默认拒绝，显式 `--replace` 才替换整个属性轨，不假装局部无损合并。锁定轨道、跟踪绑定与时间舍入碰撞须明确拒绝。
4. 应用区间以当前可见片段输出 tick 表示，写入时加 presentation-window 作者偏移。非线性速度仍由原渲染器映射；不得把源时钟误当作者动画时钟。应用包和参数以摘要留在工程 provenance 中，结果无需原外部包才能渲染。
5. capture 捕获完整作者时段，保留已有 hold/linear/ease/bezier 及控制点；不切穿曲线重新估计 easing。源许可由调用者声明，未知权利不升级为许可。包可应用到另一画幅/时长，不携带媒体路径。
6. `--dry-run`、幂等、快照、原子元数据事务、取消/超时有效。错误/回滚后原工程内容保持。已有输出不覆盖。包字节摘要和规范内容摘要分开报告。
7. 验证包括：非法输入/有限范围/别名冲突/锁定/边界/短时舍入/事务回滚；真实原生视频与独立轨迹测量；裁切前后相同帧、非线性嵌套/倒放的作者时钟比较；跨工程、导出导入、原外部包不可用后的像素一致。开发与安装、实际 Skill 证据分开。
8. 真实样例使用自制且可公开的输入，交付原图、MP4、GIF、联系表和复现脚本；记录 SHA、帧率/时长/帧数。自动解码/逐帧像素与静帧检查分别记载，未做连续播放/人工听审不能称已做。

交付前补充边界：`--idempotency-key` 在 `motion pack` 中仅允许 apply，捕获/查询明确拒绝，不在无写锁/事务的只读路径写工程记录。缩放 add 模式允许负增量，最终应用值须为正且位于 .001..100；absolute/multiply 系数须为正。

通过本批固定样例不关闭完整 G04/G12/G32/G33 或其他 G01–G38 原条件；原关闭条件不改。
