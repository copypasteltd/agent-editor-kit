# 素材、配音、翻译与配乐扩展基线

当前公开基线为 `v0.1.0-alpha.3`。本轮沿用开源、本地、面向 Agent 的 CLI，不覆盖已发布包、摘要或标签。新增代码和文档完成核验后普通推送到 `main`；后续发行采用新版本。

用户目标是系统扩充素材能力，并把社区配音、翻译、配乐等资源封装成能实际使用的内置方案。下表定义交付要求；调研或目录中的条目不能代替已安装、已生成的产物。

| 编号 | 必须形成的能力 | 验收证据 |
|---|---|---|
| M01 | 可搜索、可检查、带稳定 ID 的社区素材目录，至少覆盖音乐、短乐、音效和开源字体 | 原始来源、逐项许可、摘要、真实媒体信息和实际检索 |
| M02 | 原生 CPU 中英配音方案；具名音色、文本文件、语速、WAV、可编辑时间线导入 | 实际模型推理、音色试听、编码/时长/非静音检查、项目往返；听审范围分别说明 |
| M03 | 本地中英双向翻译，包含文本和保留时序的字幕，支持简繁处理和用户术语表 | 实际推理输入/输出、源/目标语言、模型哈希、字幕时间与 cue 数、术语与失败保护 |
| M04 | 真实社区 BGM 与短乐，可按时长截取/循环/淡入淡出、音量处理并显式接入工程 | 原始音频、实际准备结果、准确时长、实际混音和权利检查 |
| M05 | 人声与背景音乐的可控混合及压低背景音乐 | 原始分轨、混音成品、音量/时长/峰值和音轨核对 |
| M06 | 音效与中英简繁字体的实际复用 | 真实素材导入和字幕/标题渲染，不依赖再分发商业系统字体 |
| M07 | 内置资源与可选离线模型包分层；安装和正常使用不隐式联网 | 可移动安装、包清单与哈希、缺失/被修改依赖拒绝、无虚拟环境 |
| M08 | 只更新统一 `$agent-ffmpeg-local-editor` 和内部模块，保持单入口注册 | Skill 验证、实际注册入口调用与完整工作流 |
| M09 | 完整三语 README、功能手册、逐项素材与模型来源、示例和故障边界 | 文档链接/命令一致性、实际音视频/GIF/响应与可复现脚本 |
| M10 | 保存真实错误、质量不足和未完成项，明确与完整剪映目标的关系 | 每轮编号核验与状态快照；不将模型目录数量当成质量验收 |

## 已核实的候选来源

- Kokoro 1.1 中文版：模型卡声明 Apache-2.0，中英双语；sherpa-onnx 官方转换支持 103 个音色，另有 int8 包。需独立记录转换包、推理依赖及附带第三方许可。
- OPUS-MT：初查模型卡中中译英为 CC BY 4.0，英译中标为 Apache-2.0；实际下载的 2020-07-17 两个 Marian 原始包的 `LICENSE` **均为 CC BY 4.0**。本轮接入的是这两个原始包的 int8 转换，按原包保留 CC BY 4.0 与署名，不使用模型卡字段替代实际权重许可。
- Kenney：Music Jingles、Interface Sounds、Impact Sounds 的官方页面明确 CC0；下载包内的许可和实际音频数仍须检查。
- OpenGameArt：只接入逐页确认 CC0 或 CC BY 的具体资源，不把整个平台视为统一许可素材库。

## 执行与证据约束

全部新文件位于 E 盘本项目。调研下载发生在开发阶段，推理和编辑走明确本地文件；禁止 Docker、WSL、容器及虚拟环境。浏览器 UI 非必需，若使用则关闭闲置标签。现有用户模型、音色、音乐和其他项目服务不会被覆盖或自动当作可再分发资源。

来源快照保存于 `sources/materials-20261024/research/`；实际下载、转换和探测暂存于被忽略的 `product/.runtime/materials-20261024/`。公开证据和可公开样例保存于 `docs/validation/` 与 `docs/assets/`。新增内置目录和可选模型包必须携带逐项来源及许可，不用链接清单冒充可运行集成。
