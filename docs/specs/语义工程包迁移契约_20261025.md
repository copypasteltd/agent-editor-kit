# 语义工程包迁移契约（CLI 0.1.11）

本契约修复 G31 的一个已复现子项，不改变 [G01–G38](../product/GOAL_GAPS_20261025.md) 的原关闭条件。
旧 CLI 0.1.10 的 [C19 失败证据](../assets/semantic-decision-20261025-r1/demo-installed-r1/KNOWN_ISSUE.md) 保留。

| 编号 | 场景 | 必须保留或拒绝的行为 |
|---|---|---|
| P01 | 工程内 `assets/` 文件 | 保留原相对目录；索引、`vectors.f32`、预览、校准 `profile.json`/`dataset.json` 的相邻关系不变 |
| P02 | 已明确授权的外部源素材 | 先核验原始源/索引/向量/预览/档案/数据集绑定，再复制到包内；只改 URI 和由 URI 导致的派生指纹 |
| P03 | 模型与数值 | 适配器、模型、原生依赖与实现 pin、向量原字节、采样时码、标签、分数、阈值、设备均不改；转换时不推理、不下载、不重新登记 |
| P04 | 派生证据权利 | 更新后的索引/档案使用新的派生资产 SHA；Rights Ledger 追加版本，保留原版本、许可、状态、用途限制与来源。转换不授予权利 |
| P05 | 无须改 URI | 索引/档案/向量/数据集原字节与指纹不变；相同资产的别名可指向同一包成员 |
| P06 | 导入检查 | 先验证 ZIP manifest 与成员 SHA，再在新建临时目录验证内部登记、源、预览、向量、档案、数据集与派生权利 SHA，最后发布目标目录 |
| P07 | 导入失败 | 不发布新的目标工程；原有空目标目录保持为空，非空目标原样拒绝；本次临时目录正常清理 |
| P08 | 路径冲突 | 拒绝穿越、盘符相对路径、ADS、符号链接、Windows 保留名、尾随点/空格、非规范或大小写别名成员 |
| P09 | 外部运行时 | 导入只证明工程数据绑定完整。运行时/模型不随工程打包，也不在转换时执行；检索仍按原 pin 核验。换安装位置/实现/模型须明确重新登记并重建索引/档案 |
| P10 | 旧错误包 | 旧版已摊平且破坏内部绑定的 ZIP 在发布目标前拒绝；从完好的原工程用新版重新导出。没有自动修复旧损坏 ZIP 的承诺 |
| P11 | 迁移质量 | 使用冻结的 80 条查询在原工程和迁移后工程分别真实运行 CPU/CUDA；决策、命中顺序相同，分数绝对误差不超过 `1e-6`。原错误不得删除或改成正确 |
| P12 | 隔离与复用 | 迁移后真实查询前，将本批原工程及外部源移到不同路径；另做第二次导出/导入与真实统一 Skill。不得从原路径偷读素材 |

验证分开报告：合成契约检查、固定安装检查、真实 CPU/CUDA、统一 Skill、自动媒体解码、抽帧目检、连续播放和人工听审。
80 条查询是熟悉静态图的迁移回归，不是新增独立自然质量语料；3 条既有检索错误和 G26 的完整范围继续保留。
本轮不扩展私有草稿映射、HDR、自然动作理解、跨机器依赖交付或语义任务崩溃恢复。
