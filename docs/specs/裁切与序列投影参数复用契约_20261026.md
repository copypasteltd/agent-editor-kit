# 裁切与序列投影参数复用契约（2026-10-26）

承接 G32，补齐动态裁切和子序列 crop/fit/TRS 组合的重复计算优化。保留全部 G01–G38 原关闭条件；不降低分辨率、改变采样器或放宽工作栅格配额。

动态裁切：仅纯数值、与 X/Y 无关的窗口尺寸、原点和 fit 系数可在每行 X=0 初始化；像素坐标、inside 判断与原采样顺序逐像素计算。透明输入仍先预乘，再双线性采样与缩放，最后反预乘。

子序列：将裁切、fit、旋转、位置、缩放和锚点写为有序的行常量依赖图。以展开后的表达式长度估计重复成本，在 FFmpeg 的十个寄存器内选择可复用的节点；这是编译启发式，不是质量设置。双线性保留 6/7 作像素坐标，其他八个寄存器供行常量；面积采样保留 6/7/8/9 作坐标/左右边，其他六个供行常量，上下边以只读表达式传给积分函数。不得用会被像素计算覆写的寄存器存行常量。每平面/切片/行独立初始化，不跨帧缓存，不要求时间戳单调。

具有 X/Y、ld/st、random 或其他非白名单函数的内部表达式保持旧逐像素路径。只对明确纯表达式优化。原有半像素位置、浮点算术次序、裁切边界、透明色、子序列原生画布、源轴矩形积分与 authored clock 必须保持。

验收：冻结 CLI 0.1.17 对应旧函数，原生 FFmpeg 解码 RGBA 逐字节比较，覆盖 fit/fill/stretch、normalized/pixels、奇数/不同长宽比、动态关键帧、单/多切片、重复/倒退 PTS、双线性/面积采样及透明隐藏 RGB。独立单元面积交叠几何、嵌套时钟/画布/合成与 CLI 套件分别运行。组合工程交错计时三轮，冻结素材/作者设置/时间线，允许并逐项核对 render 正常追加的日志；完整解码比对视频和 PCM。
