# 可中断完整性校验契约（CLI 0.1.13）

范围是修复真实模型语义任务在同步校验期间不能及时响应超时/取消的问题。原 CLI 0.1.12 的 1 秒超时实际约 81.739 秒，原始失败证据保留；不据此关闭完整 G32/G33。

执行预算在受管语义操作入口生效，涵盖校验、采样、worker 和结果处理。`adapter-list`、`adapter-inspect`、`verify` 新增 `--timeout-seconds` / `--cancel-file`。嵌套预算不能延长外层期限；取消与超时保持 `CANCELLED` / `PROCESS_TIMEOUT`，不能改报模型完整性失败。

每次摘要必须读取全部字节才可成功。通用摘要在至多 64KiB 的读取之间检查期限；Windows 持锁摘要在至多 1MiB 的读取之间检查。取消标记最多每 25ms 检查一次，并在成功结束前强制检查。中断的部分摘要丢弃，不进入复用缓存；当前文件句柄关闭。已经完整验证的文件仍保持命令级拒写/拒删除的读锁；下一命令重新计算摘要。操作系统阻塞的文件读取不承诺立即抢占，原生模型进程保留进程树 watchdog。

中断诊断记录实际完整性读取路径、已读字节及部分摘要丢弃状态。运行目录保留诊断。操作预算先退出，再进行工作目录/事务恢复；恢复仍检查完整输出摘要，不能因取消跳过归属判定、删除已提交资源或保留可误发布半成品。

本批真实验收预先固定：原生安装版请求 1 秒超时，完整 CLI 过程须在 8 秒内返回 `PROCESS_TIMEOUT`；实际读取超过 64MiB 后写入取消标记，标记至进程结束须在 3 秒内返回 `CANCELLED`。记录绝对耗时，不把结果当通用性能保证，不停止其他 GPU 任务。CPU/CUDA 正常查询与已知错误继续保留；旧适配器实现 pin 不改写，新安装版使用显式新登记。

相关代码为 `execution_control.py`、`artifact_locks.py`、`utils.py` 和语义控制器/worker；测试必须验证真实文件字节、Windows 文件共享与句柄释放、预算嵌套、错误码及提交前后恢复。机器检查不替代自然画面、声音或语义验收。
