# 语义任务发布与中断恢复契约（CLI 0.1.12）

本轮继续完整 [G01–G38](../product/GOAL_GAPS_20261025.md)，主要推进 G33，并补充 G32 的分阶段耗时。
当前 Skill 在安装版核验通过前继续使用既有固定版本。功能实现、合成契约、真实模型、故障注入和发行分别记账。

| 编号 | 要求 | 验证方法 |
|---|---|---|
| J01 | adapter-register/index/calibrate/search 使用带原生租约的受管目录 | 新任务记录及真实命令；活跃租约在 dry-run 中保留 |
| J02 | index/calibrate 整棵目录发布前记录文件 SHA、文件/目录身份与唯一目标 | 观察持久清单先于同盘 rename；不覆写已存在目标 |
| J03 | 正常错误先恢复元数据，再按身份清理未引用产物 | 注入发布后/账本写入失败；保留原素材及执行请求/响应 |
| J04 | 强制结束后的未提交产物可显式回收 | 固定安装版真实模型产物，在发布后/提交前终止原生 CLI，恢复后元数据与原输入相同 |
| J05 | 提交后的整个索引/校准目录保留 | 提交后终止，恢复缓存后仍可用原 ID 检索，数据/阈值不变 |
| J06 | 任一资产或活动权利证据引用目录内部文件时，保留整棵树 | 独立资产、权利引用测试；不把未直接登记的同目录文件删掉 |
| J07 | 任何修改、文件/目录替换或新增内容导致保留 | 同字节不同身份、额外文件/空目录及不明清单分别验证 |
| J08 | dry-run 不修改元数据、发布内容或诊断；重复恢复稳定 | 冻结完整快照，检查前后字节与已回收结果 |
| J09 | 新目录中的请求、响应、失败和阶段记录保留供复查 | 正常结束保留诊断；显式清理前保存需要的样例，不从清理重建推理证据 |
| J10 | 旧 cache/semantic-jobs 与未知目录保留 | 不自动接管历史目录；按未知记录返回保留理由 |
| J11 | 取消、超时和父进程结束只影响本任务所属进程树 | 原生进程句柄与终止记录；不停止其他 GPU 程序 |
| J12 | 新受管实现纳入适配器 pin | 显式登记新适配器并重建；不改写旧 SHA |
| J13 | 模型推理与检索质量不因恢复功能改写 | 冻结原 11 资产、40 校准、80 查询及三条已知错误；不据新结果重新调阈值 |
| J14 | 观测导入、完整性核验、加载与推理阶段 | 真实 worker 阶段文件与耗时；不称为独占性能 benchmark |

目录预算沿用 2MiB 清单、每次扫描 256 项/每项 10000 条目；单个语义发布树最多 4098 文件。
发布只允许 index 的 `assets/semantic/<24hex>` 和 calibrate 的 `assets/semantic-calibration/<24hex>`。
恢复基于同一主机合作式文件系统，保留未知或变化内容；不是恶意主机隔离、推理断点续跑、断电/磁盘耗尽或完整 G33 验收。
常驻模型、多命令加载复用、自然语义质量、跨机器交付及其余全部原条件仍需继续完成。
