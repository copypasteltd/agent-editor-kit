# 语义条件与素材库校准拒识契约

此契约扩展 G26，不改变其原目标。图文检索、自然动作、跨镜头身份、音频检索、配乐推荐和大库性能仍分别验收。开发源码、安装版与真实统一 Skill 的结果必须分开记录。

## 查询条件

默认 `semantic search --query-mode clauses` 将有界的中英“正向描述，不是/排除/not/excluding 另一描述”拆成可检查的条件。响应保留用户原文、解析方式、全部正向/排除描述及逐条件分数。无法确定范围的否定、双重否定和关系从句返回 `SEMANTIC_QUERY_SCOPE_REQUIRES_REVIEW`，不能静默改写成肯定句。

查询文件可提供 `id/text/include/exclude`，`include` 为 1–8 项，`exclude` 为 0–8 项。展示原文不替代实际条件；Agent 应向客户说明解析后的含义。条件不能重复或自相矛盾。查询文件不允许标签、答案或执行参数。

```json
{"queries":[{"id":"cat_without_coffee","text":"猫，不是咖啡","include":["一只猫"],"exclude":["一杯咖啡"]}]}
```

同一采样帧上的全部正向描述分别计算余弦相似度，最低正向分数作为决策分数；只有它严格高于每个排除描述的分数时，该帧才有资格返回。不能用一个视频的不同帧分别满足多个条件。排除是相对模型证据，不是经过定位验证的对象不存在证明。

`--query-mode raw` 保留旧版整句排名，用于研究、历史失败复现和人工候选查看；不能同时使用显式条件或校准档案。单一批次按实际条件文本去重并共享一次模型初始化。仍禁止静默截断超过 64 token 的输入。

## 经验校准

`semantic calibrate --calibration-id ID --input FILE --index-id INDEX` 接受 `agent-semantic-calibration-set-v1`：必须提供 `scope` 和 32–128 条不重复查询，正向、库外各至少 16 条。每条包含查询字段和 `expected_asset_ids`；空列表表示库内没有匹配。标签仅由控制器评价，不送入模型 worker。

默认库外误接受预算为 0.05、正向正确覆盖最低为 0.75。按预先声明的库外分数顺序统计量确定阈值，搜索须严格大于阈值。正向覆盖只计被接受且第一项正确的查询，错选及全部拒绝不能算通过。校准未通过时保留报告，但不登记可用档案。

这是对提供语料的经验校准，不是概率、分布无关保证、语义真值证明或任意新库的可靠拒识保证。冻结的独立查询须另行评价；不能查看其结果后反复调阈值并仍称独立验收。

## 绑定、交付与恢复

档案绑定模型/实现摘要、完整索引指纹、条件协议、素材类型过滤、实际 CPU/CUDA 设备和设备编号。跨库、类型过滤变化、CPU/GPU 替换、源/预览/向量/档案/校准语料字节变化均不能静默复用。查询模式和参考图不适用时明确拒绝。

成功校准将原始语料副本和自含结果档案保存为工程生成资产，登记 Rights Ledger 派生依赖和操作快照。工程包应保留这些资产；移动后仍须明确重登记已有本地模型，禁止绕过旧绝对路径/实现摘要。发布时不自动授予原素材、模型或校准文本的权利。

CLI 元数据事务发生写入失败时回滚，当前调用未提交的产物回收，诊断保留；已有档案不覆盖。此契约不声称新增校准任务已经覆盖强制断电/全部崩溃恢复或 G33 的完整故障矩阵。

## 搜索结果的含义

| 状态 | 含义 | Agent 使用要求 |
|---|---|---|
| `candidates_require_review` | 未提供适用档案，只是排序候选 | 不自动当作已匹配；展示实际预览及分数 |
| `calibrated_match` | 条件和经验阈值通过 | 仍检查画面、时间范围、语义与权利 |
| `no_calibrated_match` | 当前没有候选通过条件和经验阈值 | 明确报告暂无经校准候选，不编造素材 |
| `SEMANTIC_QUERY_SCOPE_REQUIRES_REVIEW` | 自动解析无法确定否定范围 | 先澄清为显式正向/排除条件 |

仍按实际采样 PTS 返回可编辑点引用，片段时长须另行审核；命中单帧不证明整段内容符合条件。参考图查询保留现有候选检索，不把文本校准档案套用到图像检索。

## 冻结实测协议

[冻结协议](../validation/evidence/semantic-decision-20261025-r1/frozen/protocol.json)包含 11 张图、10 类画面、40 条校准查询、60 条独立措辞查询与原 20 条回归查询。与旧基准共用熟悉的静态图片，不是训练未见图片、独立人类盲评或自然运动验收。开发、安装、CPU/GPU 和注册 Skill 的结果分别记录；所有未通过项保留。

方法参考：[SigLIP2 官方模型资料](https://huggingface.co/google/siglip2-base-patch16-224)与[Transformers 官方实现](https://github.com/huggingface/transformers/blob/main/src/transformers/models/siglip/modeling_siglip.py)。模型输出余弦和本地经验阈值在本产品中都不标为匹配概率；不以模型演示中的 sigmoid 数值替代素材库验收。
