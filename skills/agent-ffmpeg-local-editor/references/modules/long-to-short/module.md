# 长视频、课程和口播转短片 / long-to-short

[Unified entry](../../../SKILL.md) · [Shared runtime](../../runtime.md)

Local lesson/talk + reviewed text → rough cuts/short projects

Commands: `media highlights/smart-cut; timeline compose`. Review candidate segments; no autonomous semantic-director claim.

## Workflow

Inspect the recording and supplied transcript. Use `media highlights --help` to propose candidates, then
review complete statements and surrounding context. Preserve selected source ranges, create explicit timelines
with captions/audio, preview and render. Without ASR weights use supplied transcripts; do not invent quotations.
