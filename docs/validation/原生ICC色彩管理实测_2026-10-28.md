# 原生ICC色彩管理实测 / Native ICC verification — 2026-10-28

新增**原生 ICC 色彩管理**：明确本地 RGB ICC v2/v4、SHA、四种渲染意图与黑点补偿，由 LittleCMS 2.19.1 直接转换到线性工作 RGB；贯通素材、浮点导出、预览缓存和可编辑工程包。

26项源码专项、26项安装专项和287项安装兼容检查分别通过。C56独立核对首帧230400像素、全48帧色块与完整非静音音画工程包重放；每次48次实际GPU Bloom。ICC CMM使用CPU，支持的合成/光晕使用原生GPU。范围是RGB源配置：任意ICC输出、软打样、CMYK、内嵌配置自动识别、完整ACES和自然HDR监看仍待补齐，38项原目标关闭条件保留。

LittleCMS2.19.1 MIT source pinned at commit `21c582a594fe5279f90c0b93437c398f93bf62b0`; native LLVM/MinGW Windows build, no virtualization. DLL SHA `b0149bbc4fa977a23faeddf3a006b9c04cd8e6748dd3a6f19d868828842c3350`. [Upstream release](https://github.com/mm2/Little-CMS/releases/tag/lcms2.19.1). CMM encoded version2190 is the upstream header value for this hotfix tag. Pillow reference uses a separate shipped CMM2.17; the product does not use its eight-bit conversion.

Source-r1 retained two oracle issues: serialized v2 u8Fixed8 gamma differs from the authoring request, and the installed Pillow version exposes its CMM version differently. Source-r2 retained a CLUT fixture containing only A2B0 while requesting A2B1 relative colorimetric intent; actual CMM correctly rejected it. The final original fixture includes the requested table. Tolerances were not relaxed to mask these failures. Source-r3 and installed-r1 both pass26 checks.

Activation-r1 was refused because activation started before the new Skill pin finished. Pin completion was confirmed,then activation-r2 verified four existing packs and registered the single junction successfully. No source fallback was enabled.
