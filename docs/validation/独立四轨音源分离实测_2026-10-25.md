## 预先冻结的输入和门槛

[frozen-fixture.json](evidence/four-stems-20261025-r1/frozen-fixture.json) 的 SHA-256 为 `50ce0ec902e7ce9e0b5a04cc7201530eaf1c82142eb6ca14e97797fce5d54f02`。6 秒、44,100Hz、双声道、264,600 个样本帧；既有中文语音与独立确定性合成鼓、贝斯、和弦组成受控混音。四条原始参考在推理前冻结，固定 seed 20261025、各源 RMS 0.04。该语音来源权利未确认，媒体只留本地。

另取已有 CC0 音乐目录中 DST《MindStream》的 20–26 秒；它没有独立四轨真值，只验执行、文件、设备和数值诊断。没有据这段音乐计算分离准确率或宣称听感通过。

预先门槛：每源 SI-SDR 相对混音改善至少 3dB；CPU/GPU 每源最大绝对差≤0.005、RMS 差≤0.0001。它们是本次受控实验门槛，不能替代自然泄漏、瞬态、可懂度、伪影或人工听感验收。

## 信号诊断与性能边界

四轨保留模型自己的独立预测：不以源减人声伪造其他三轨，不独立归一化、限幅或做混合一致性投影。共享输入归一化、DC/4 恢复与三角 overlap/add；输出精确样本数。

受控 CPU 原始四轨和相对输入 RMS 误差 0.007231723、最大绝对误差 0.28631724；CUDA RMS 0.007232491。自然片段 RMS 误差约 0.0116038、最大差约 0.105624。该诊断如实保留，不自动修成“完美重构”，也不是独立质量阈值。

实测 GPU peak allocated 为 550,677,504 bytes。首轮开发 CPU 命令约 179.74 秒（含完整性/导入/加载，worker 160.273 秒），安装版 CPU 约 40.85 秒、CUDA 约 12.88 秒；这不是成对隔离冷启动基准，不能据此宣称固定 GPU 倍速。依赖加载、主机 RAM、长片、并发和其他 GPU 型号仍未完成系统验收。
