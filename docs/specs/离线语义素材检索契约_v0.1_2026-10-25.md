# 离线语义素材检索契约 v0.1

关联 G26 素材语义检索、G27 自动选材、G32 GPU 与资源。目标是让 Agent 从实际本地图片和视频中按自然语言或参考图找候选，返回源资产 ID、源文件摘要与视频采样时间，进入既有可编辑时间线。全部 38 组完整目标继续保留；本契约不以关键词替代模型推理，也不把相似度当成画面事实或概率。

## 实现要求

1. 本地注册 safetensors 图文编码模型、原生 Python、来源/许可与实现摘要；禁用远程代码、运行时下载、Docker、WSL 和虚拟环境。开发获取单独记录固定版本/哈希。GPU 优先、严格 GPU 和 CPU 均有明确选择与实际设备证据。
2. 对明确选择的项目图片/视频建立真实模型向量索引。视频采样策略、时间、帧输出摘要和预算写入清单。超过预算拒绝而不是静默漏掉资产；采样点不能冒充动作的完整时间范围。
3. 向量为有限、非零、单位化 float32；维度、行数与记录逐一绑定。清单和二进制向量分别校验；源、模型、实现或索引被改动时拒绝过期/损坏结果。已有输出不覆盖，失败/取消不登记半成品。
4. 支持自然语言批量查询和本地参考图查询，独立返回 cosine 排名、资产与采样时间。明确过滤、去重/每资产最优证据、模型和文本预处理；输入过长不得静默截断。原始文本与索引不因搜索改变。
5. 模型 forward 运行在有超时/取消的独立原生进程；模型复用至少覆盖同一批次。记录加载、推理、设备、峰值 GPU 内存与回退。检索过程不修改工程素材或其权利状态。
6. 查询命中项目资产可直接用于时间线；外部素材仍须经原 ingest 与权利流程。索引不赋予任何版权、身份或内容使用许可。

## 预先声明的验证

在首次模型检索前固定测试集与查询/相关性标签，候选模型不接收标签。至少包含中英描述、同类干扰、否定/不匹配查询、同画面不同文件名、视频内多个采样点及本地参考图。报告全部查询 top-1、recall@k 与失败，不反复改查询、删难例或根据预测重写真值。小样例只证明该样例相关性，不能关闭人物、动作、跨镜头语义或自然广告全集质量。

基础正确性涵盖向量规范、路径/预算/类型、损坏/篡改/过期、重复输出、取消和工程不变。实际 GPU 与 CPU 推理分别留证，检索结果至少完成一条可编辑时间线和真实渲染核验。安装版、统一 Skill、三语 README、可复查预览与许可同步交付后，才计入当前可用能力。

自然动作推理、音频内容 embedding、跨镜头身份、配乐/音效推荐、长期大库性能和独立 Agent 成功率继续按原完整目标推进。
