# 参考片结构复刻与原创素材替换 / reference-remake

[Unified entry](../../../SKILL.md) · [Shared runtime](../../runtime.md)

Local reference + replacement assets → editable remake

Commands: `media understand; timeline compose`. Rebuild structure; no automatic acquisition or rights grant.

## Workflow

Analyze local reference evidence, separate timing/layout/motion from copyrighted creative assets, and map
replacement media to an explicit edit plan. Use supported timeline and effect contracts. Keep reference and
replacement provenance separate; preview comparison frames and record approximation or unsupported elements.
